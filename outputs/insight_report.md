# 实验四：AI+Python消费者洞察引擎

## 1. 数据概览
本次使用蓝牙降噪耳机教学模拟评论数据。原始数据共 402 条，清洗去重后有效样本 399 条，覆盖索尼、Bose、Apple AirPods、华为 FreeBuds 四个品牌。

## 2. 程序计算与Skill编码分工
- Skill语义编码：情绪、需求、痛点、证据片段和置信度。
- Python统计：计数、占比、排序、品牌对比和证据表生成。
- 统计分母：399 条有效编码评论。

## 3. 痛点结论
最高频负面主题为“佩戴舒适”：93 条/399 条，占 23.3%。完整排行见 `pain_point_statistics.csv`。

## 4. 事实、推断和建议
**事实：** 负面主题按评论ID去重后统计，并保留分子、分母和百分比。

**推断：** 高频痛点代表消费者体验中较集中的阻碍，但不能单独证明其导致购买流失。

**建议：** 后续可按品牌分别检查该痛点，并用问卷或A/B测试验证产品卖点和价格方案。

## 5. 证据追溯
每个重点主题至少绑定3条原始评论证据，见 `evidence_table.csv`。

## 6. 限制
数据为教学模拟数据，语义编码采用本地规则复现 GitHub Skill 的字段契约；如接入大模型，应保留相同JSON结构并重新进行10条人工抽检。
